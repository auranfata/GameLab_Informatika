# 🎮 Game Lab – Teknik Informatika

Game Lab adalah sebuah **project eksplorasi dan pembelajaran** yang dikembangkan oleh divisi/komunitas **Teknik Informatika** sebagai media edukatif, interaktif, dan menyenangkan untuk memperkenalkan logika pemrograman, dasar pengembangan game, serta pemanfaatan teknologi web modern.

Project ini ditujukan untuk **masyarakat umum**, pelajar, dan mahasiswa sebagai sarana belajar sambil bermain (*learning by playing*).

---

## ✨ Tujuan Project

- Menjadi media pembelajaran interaktif berbasis web
- Mengenalkan konsep dasar logika, algoritma, dan game development
- Menyediakan mini games ringan yang mudah dimainkan
- Menjadi wadah eksplorasi dan pengembangan kreativitas mahasiswa Teknik Informatika
- Membangun portofolio project berbasis teknologi web

---

## 🕹️ Daftar Game

### 1. Tic Tac Toe
Game klasik dua pemain (Player vs Player) dengan fitur:
- Indikator giliran pemain
- Deteksi menang & seri
- Efek suara (move, win, draw)
- UI berbasis Bootstrap
- Font global: **Poppins**

### 2. Quiz Informatika
Mini quiz edukatif dengan topik **Teknik Informatika**, meliputi:
- 5 pertanyaan pilihan ganda
- Perhitungan skor akhir
- Penilaian hasil:
  - Skor di atas rata-rata → pesan motivasi bergabung ke Teknik Informatika
  - Skor di bawah rata-rata → ajakan belajar lebih dalam dunia teknologi

### 3. Flappy Bird (Web Version)
Game arcade berbasis Canvas dengan fitur:
- Latar belakang bergambar
- Animasi burung
- Sistem skor
- Tampilan skor akhir
- Tombol mulai ulang
- Kontrol menggunakan keyboard (spasi)

---

## 🛠️ Teknologi yang Digunakan

- **HTML5**
- **CSS3** (Global Style)
- **JavaScript (Vanilla JS)**
- **Bootstrap 5**
- **Canvas API**
- **Google Fonts (Poppins)**
